# 语伴 · 外语学习小程序

纯前端、零后端、开箱即用的微信小程序，**以口语练习为核心**：句子/情景对话/单词跟读 + 逐词高亮(K歌字幕) + A-B复读 + 角色扮演 + 自建素材导入 + 录音回放 + 发音客观评分（可选）+ 重点复练 + **今日待练清单**，辅以单词卡片、FSRS 智能复习、小测验、查词（**收藏夹 + 搜索历史**）、错词本、录音历史、打卡日历、**口语流利度曲线**、成就徽章和进度统计。英语为主（内置 220 词 + **112 句** + 8 组情景对话，标注 CEFR 难度），结构上预留多语言扩展。发音有**三级自动降级**（有道 → 备用源 → 同声传译合成），断网/接口挂了也不误事。

## 导入与运行

1. 打开 **微信开发者工具** → 导入项目
2. 目录选择本文件夹（`语言学习小程序`）
3. AppID 可选择「测试号」（`project.config.json` 里已填 `touristappid`，游客模式也能跑大部分功能）
4. 点击「编译」即可在模拟器里使用；**口语录音、发音评分建议真机预览**

发音使用有道公开 TTS 接口，**需联网**；若主源不可用会自动降级到有道备用地址或微信同声传译本地合成（需启用插件）。录音用微信原生录音能力，需授权麦克风。

| 测验 | 随机 10 题（选择题 + 拼写题），即时判定、显示例句，结束给出正确率 |
| 查词 | 按单词/释义/例句实时搜索，**按考试分类（四级/六级/考研/雅思托福）筛选**，**⭐生词收藏夹 + 搜索历史**，点击展开例句、听发音 |
| 错词本 | 自动收集答错过的词，按错误次数排序，集中重练 |

| **家庭排行榜** | 按今日口语/连续天数/累计学词给家人排名，数据都在本机 |
| **全家录音墙** | 跨档案汇总所有人的录音，回放 + **家人文字点评**互相鼓励；**有未读点评时首页入口显示红点** |
| **邀请朋友** | 一键转发小程序卡片 + 复制邀请文案 |
| **学习提醒** | 设提醒偏好和时间（真推送需后台，页面内附免费替代方案） |

口语练习流程（tabBar 第 2 项「口语」）：

```
选类型(句子/对话/单词/自建) + 难度(A1-B2) + 场景 → 听标准音/慢速（逐词高亮跟读）
     → 🔁A-B复读单句循环 / 🎭角色扮演隐藏台词接话
     → 点麦克风录音（如已启用同声传译插件，同时给出客观发音分）
     → 听我的回放对比 → 自评：🔁再练练 / 👍基本流利 / 🌟很流利
     → 「再练练」进重点清单 → 顶部「🎯 重点复练」一键集中攻克
     → 「🎧 我的录音」回听所有练习轨迹
```

所有学习进度、口语记录、录音都存在微信本地 `Storage` / 本地文件，无需登录、不上传任何数据。

## 性能与流畅度

针对小程序"同步 Storage 慢、setData 大列表卡"两个主要卡顿源做了优化，纯内部改动，**用法完全不变**：

- **数据读取缓存**：档案信息、进度/统计/设置、口语记录、在线词库缓存都加了进程内缓存，同步读次数从上百次降到个位数（实测首页一轮刷新从约 20+ 次同步读降到 2 次）；写入即时刷新、导入/切档案自动失效，不会读到脏数据。
- **查词页增量渲染**：内置 220 词不再一次性全渲染，首屏只显示 30 条，下拉"加载更多"；搜索历史改为按"搜索键"记录，不再每敲一个字都写 Storage。
- **统计页去重读取**：设置、每日数据、掌握数等只读取一次后复用。
- **大列表增量渲染**：今日待练（最多 660 项）、错词本（最多 220 项）首屏只渲染 30 条，下滑「加载更多」追加，不再一次性铺满页面；口语页队列超过 20 条时，进度指示从「每个条目一个圆点」改为「进度条 + 3 / 220」，节点数从上百个降到 2 个。
- 缓存正确性有单元测试覆盖（读次数下降、写后即时可见、失效后能发现外部改动）。
- **异常兜底**：`app.js` 挂了 `onError` / `onUnhandledRejection` / `onPageNotFound`，页面出错不再静默白屏，页面路径失效会自动回首页；本地写入失败（空间满等）会明确提示用户先备份，不会让你以为进度已保存。

## 给家人朋友用（多人场景）

一台设备、一家人共用时，进首页点顶部「切换家人档案」：

- **每人一份独立进度**：档案间学习/口语/统计/录音完全隔离，不会串号。升级前的老数据自动归到名为「我」的默认档案。
- **儿童 / 长辈模式**：给每个档案单独设，字号自动放大（长辈超大字），界面更友好；也能在统计页手动微调字号/深色/震动。
- **家庭排行榜**：首页「家庭排行榜」看今天谁练得最多，可切换按连续天数、累计学词排。
- **全家录音墙 + 点评**：听家人录音，点「点评」写一句鼓励，互相打气。
- **邀请朋友**：首页「邀请朋友」转发卡片或复制文案；加体验成员扫码即用、免费免审核（详见 [上线合规清单.md](上线合规清单.md)）。
- **学习提醒**：本机能存提醒偏好；真定时推送需后台+模板 ID，页面内给了手机闹钟等免费替代。
- **全家包备份**：统计页「导出全家包」把一家人所有档案+录音一次性复制成文本，换设备「导入全家包」可选合并或覆盖，全家搬家不丢数据。

数据始终只在这台设备的微信里，不联网、不上传。想给另一台设备用，用「统计 → 导出/导入进度」或「导出/导入全家包」迁移。哪些功能受"零后端"限制做不到，见 [能力与边界说明.md](能力与边界说明.md)。

## 关于发音客观评分（进阶可选，现阶段可忽略）

默认使用**自评**（再练练/基本流利/很流利），导入即可用、无需任何后台配置。代码里已内置「微信同声传译」实时识别评分的接入（录音时并行识别、与目标文本比对打分），但它是**可选的进阶功能**：需要在微信公众平台后台添加该插件，并在 `app.json` 声明插件后才能启用（届时可以让我帮你改）。**未配置时自动静默降级为纯自评，不影响任何功能。** 用测试号（touristappid）时无需理会这一项。

## 换设备迁移进度

在「统计」页点**导出进度**，备份数据（含学习/口语/打卡）复制到剪贴板，粘贴到备忘录/微信收藏保存；换设备后点**导入进度**粘贴即可恢复。全程不联网、不需要账号。导入时会自动迁移旧版本数据。

## 扩展素材 / 多语言

- **加单词**：编辑 `utils/words.js` 的 `WORDS.en` 数组，按现有字段填写即可。
- **加句子/对话**：编辑 `utils/sentences.js` 的 `SENTENCES` / `DIALOGUES`，`level` 填 A1/A2/B1/B2 即可自动出现在难度筛选。
- **不写代码加素材**：口语页 →「📥 导入素材」，每行一句 `英文|中文`，保存后切到「✏️ 自建」跟读。
- **加语种**：在 `WORDS`、`SENTENCES`、`DIALOGUES` 下各加语种键，并在 `getLangMeta()` 补语种名和 TTS 代码；首页 `pages/index/index.js` 的 `langs` 数组同步加上。示例日语词库已内置。

纯函数（FSRS/高亮/徽章/相似度/素材数据）有 Node 单元测试：


## 在线词库更新（可选，需你自己的备案域名）

默认完全离线、用内置词库。若你有**已备案的 https 域名**，可把词库放上去，以后加词改句**不用重新提交小程序版本**：

1. 按 **[在线词库部署-OSS.md](在线词库部署-OSS.md)** 把 `deploy/data.json` 传到阿里云 OSS 并绑定备案域名。
2. 把得到的 https 地址填进 `utils/online-data.js` 的 `DATA_URL`（留空即不启用）。
3. 小程序后台把该域名加进 **request 合法域名**（测试号可先跳过）。

拉不到 / 没配置时自动用内置词库，**完全无感**。以后更新：改素材 → 跑 `node deploy/export-data.js` → 覆盖上传 `data.json` 即可。

## 已知说明

- 发音依赖第三方公开接口，弱网/离线时会自动切换备用源并给出提示；如需完全离线，可配置「微信同声传译」插件替代。
- 录音回放用微信原生 `RecorderManager` + `InnerAudioContext`；录音文件保存到本地（最近 30 条），超量自动删除最旧的，避免占满空间。
- 发音客观评分依赖微信同声传译插件的**实时语音识别**，它是可选的；未添加插件或识别失败一律静默降级为纯自评，绝不阻断练习。
- 统计图表用原生 Canvas 2D 绘制，未引入任何第三方图表库。

## 进阶（可选）：启用发音客观评分

只有在你**已经用真实 AppID 上线、且想加客观发音分**时才需要做；测试号阶段完全不用管：

1. 登录微信公众平台 → 设置 → 第三方插件 → 添加插件「微信同声传译」（WechatSI），并等待审核通过
2. 在 `app.json` 里增加插件声明（拿到 AppID 后可让我帮你填）：
   ```json
   "plugins": { "WechatSI": { "version": "0.3.5", "provider": "插件AppID" } }
   ```
3. 添加后 `utils/speech-score.js` 会自动检测到插件并启用识别评分，**无需改其他代码**
4. 不做以上任何操作：所有功能照常使用，只是没有客观分数这一项
