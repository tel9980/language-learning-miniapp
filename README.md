# 语伴 · 外语学习小程序

纯前端、零后端、开箱即用的微信小程序，**以口语练习为核心**：句子/情景对话/单词跟读 + 录音回放 + 发音客观评分（可选）+ 重点复练，辅以单词卡片、FSRS 智能复习、小测验、查词、错词本、录音历史、打卡日历、成就徽章和进度统计。英语为主（内置 220 词 + 20 句 + 5 组情景对话），结构上预留多语言扩展。

## 导入与运行

1. 打开 **微信开发者工具** → 导入项目
2. 目录选择本文件夹（`语言学习小程序`）
3. AppID 可选择「测试号」（`project.config.json` 里已填 `touristappid`，游客模式也能跑大部分功能）
4. 点击「编译」即可在模拟器里使用；**口语录音、发音评分建议真机预览**

发音使用有道公开 TTS 接口，**需联网**；录音用微信原生录音能力，需授权麦克风。

## 功能说明

| 页面 | 功能 |
|---|---|
| 首页 | 今日口语次数/打卡/掌握概览、口语练习主入口、今日复习目标、切换语种、6 个功能入口 |
| **口语** | 核心页：**句子 / 情景对话 / 单词**三种跟读；听标准音/慢速/例句 → 录音 → 回放对比 → 自评/机评；「再练练」自动进重点复练清单 |
| 我的录音 | 录音历史列表、回放、单条删除、清空；最多保留最近 30 条 |
| 学习 | 卡片翻转看释义；三档记忆评分；**FSRS 动态间隔**自动排期复习 |
| 测验 | 随机 10 题（选择题 + 拼写题），即时判定、显示例句，结束给出正确率 |
| 查词 | 按单词/释义/例句实时搜索，**按考试分类（四级/六级/考研/雅思托福）筛选**，点击展开例句、听发音 |
| 错词本 | 自动收集答错过的词，按错误次数排序，集中重练 |
| 统计 | 口语数据、**近 4 周打卡日历**、**成就徽章（8 枚）**、近 7 天复习柱状图、掌握分布、每日目标、进度导出/导入 |

口语练习流程（tabBar 第 2 项「口语」）：

```
选类型(句子/对话/单词) + 场景 → 听标准音/慢速 → 看例句跟着说
     → 点麦克风录音（如已启用同声传译插件，同时给出客观发音分）
     → 听我的回放对比 → 自评：🔁再练练 / 👍基本流利 / 🌟很流利
     → 「再练练」进重点清单 → 顶部「🎯 重点复练」一键集中攻克
     → 「🎧 我的录音」回听所有练习轨迹
```

所有学习进度、口语记录、录音都存在微信本地 `Storage` / 本地文件，无需登录、不上传任何数据。

## 关于发音客观评分（进阶可选，现阶段可忽略）

默认使用**自评**（再练练/基本流利/很流利），导入即可用、无需任何后台配置。代码里已内置「微信同声传译」实时识别评分的接入（录音时并行识别、与目标文本比对打分），但它是**可选的进阶功能**：需要在微信公众平台后台添加该插件，并在 `app.json` 声明插件后才能启用（届时可以让我帮你改）。**未配置时自动静默降级为纯自评，不影响任何功能。** 用测试号（touristappid）时无需理会这一项。

## 换设备迁移进度

在「统计」页点**导出进度**，备份数据（含学习/口语/打卡）复制到剪贴板，粘贴到备忘录/微信收藏保存；换设备后点**导入进度**粘贴即可恢复。全程不联网、不需要账号。导入时会自动迁移旧版本数据。

## 扩展词库 / 多语言

- **加单词**：编辑 `utils/words.js` 的 `WORDS.en` 数组，按现有字段填写即可。
- **加句子/对话**：编辑 `utils/sentences.js` 的 `SENTENCES` / `DIALOGUES`。
- **加语种**：在 `WORDS`、`SENTENCES`、`DIALOGUES` 下各加语种键，并在 `getLangMeta()` 补语种名和 TTS 代码；首页 `pages/index/index.js` 的 `langs` 数组同步加上。示例日语词库已内置。

## 已知说明

- 发音依赖第三方公开接口，弱网/离线时会自动切换备用源并给出提示；如需完全离线，可配置「微信同声传译」插件替代。
- 录音回放用微信原生 `RecorderManager` + `InnerAudioContext`；录音文件保存到本地（最近 30 条），超量自动删除最旧的，避免占满空间。
- 发音客观评分依赖微信同声传译插件的**实时语音识别**，它是可选的；未添加插件或识别失败一律静默降级为纯自评，绝不阻断练习。
- 统计图表用原生 Canvas 2D 绘制，未引入任何第三方图表库。

## 进阶（可选）：启用发音客观评分

只有在你**已经用真实 AppID 上线、且想加客观发音分**时才需要做；测试号阶段完全不用管：

1. 登录微信公众平台 → 设置 → 第三方插件 → 添加插件「微信同声传译」（WechatSI），并等待审核通过
2. 在 `app.json` 里增加插件声明（拿到 AppID 后可让我帮你填）：
   ```json
   "plugins": { "WechatSI": { "version": "0.3.5", "provider": "插件AppID" } }
   ```
3. 添加后 `utils/speech-score.js` 会自动检测到插件并启用识别评分，**无需改其他代码**
4. 不做以上任何操作：所有功能照常使用，只是没有客观分数这一项
