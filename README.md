# 语伴 · 外语学习小程序

纯前端、零后端、开箱即用的微信小程序，**以口语练习为核心**：句子/情景对话/单词跟读 + 逐词高亮(K歌字幕) + A-B复读 + 角色扮演 + 自建素材导入 + 录音回放 + 发音客观评分（可选）+ 重点复练 + **今日待练清单**，辅以单词卡片（**可按分类学新词**）、FSRS 智能复习、小测验、查词（**收藏夹 + 搜索历史**）、错词本、录音历史、打卡日历、**口语流利度曲线**、成就徽章和进度统计。英语为主（内置 **440 词 + 112 句 + 8 组情景对话**，日语 **100 词 + 100 句 + 8 组情景对话**，均标注 CEFR 难度；**日语和英语的句子朗读都用随包离线音频**，不联网也能听），词表按「四级/六级/考研/雅思托福」+「日常/情绪/工作/交通/购物/学校/家庭/身体/天气/形容词/动词…」分类筛选，结构上预留多语言扩展。发音有**四级自动降级**（有道 → 有道备源 → 百度翻译 → 同声传译合成），断网/接口挂了也不误事；**听过的句子会缓存成本地文件**，同一句再听 0 请求。

## 导入与运行

1. 打开 **微信开发者工具** → 导入项目
2. 目录选择本文件夹（`语言学习小程序`）
3. AppID 已填好真实小程序 AppID（`project.config.json` 里 `appid: wx95cccc560a35d484`）；用自己的号预览/真机调试时，开发者工具会要求你是该小程序的开发者或体验成员
4. 点击「编译」即可在模拟器里使用；**口语录音、发音评分建议真机预览**

发音使用公开 TTS 接口，**需联网**；英语主源（有道）对整句经常返回 500，会自动降级到百度翻译 TTS，再不行才用同声传译本地合成（插件 `WechatSI` 已添加，provider `wx069ba97219f66d99`，v0.3.10）。**日语不走在线合成**：333 条日语朗读（100 句 + 33 行对话 + 100 词 + 100 条例句）已预先生成为 mp3，随包发布、不联网也能听；英语的 140 条句子/台词朗读同样随包。原因与做法见「离线音频与分包」一节。录音用微信原生录音能力，需授权麦克风。网络发音下载过一次就缓存进本地（上限 3MB，按最久未使用淘汰），同一句再听不再联网；占的空间在「统计 → 使用设置 → 发音缓存」里能看到并一键清空。

## 离线音频与分包（为什么日语必须离线、英语也随包）

日语整句找不到可靠的免费合成源，实测结论：

| 来源 | 日语单词 | 日语整句 |
| --- | --- | --- |
| 有道 `dictvoice` | 可以（必须带 `le=jap`，不带会返回 1920 字节静音占位文件） | 返回 0 字节 / 500 |
| 百度 `fanyi.baidu.com/gettts` | 403 | 403 |
| 微信同声传译 `textToSpeech` | 官方文档只列 `zh_CN`/`en_US` | 同左 |

百度智能云、阿里云、讯飞**都有日语 TTS**，但都需要 AccessKey 签名：密钥放前端会被反编译拿走（盗刷账单），
所以必须配后端或云函数，等于放弃「纯前端零后端」这个定位。因此这里选择**离线预生成**：

- 音频用 [edge-tts](https://github.com/rany2/edge-tts)（微软 Edge 朗读通道，免费、无需密钥）合成，
  日语 `ja-JP-NanamiNeural`、英语 `en-US-JennyNeural`
- 再用 ffmpeg 压到 16kHz / 16kbps 单声道，单条约 5–7KB
- 播放时 `audio.speak()` 优先用 `utils/local-audio.js` 里的路径，**0 请求、0 配额、断网可用**；
  没有对应音频的条目（自建素材、日语在线兜底）照旧走在线降级链
- 慢速按钮对本地文件用 `playbackRate = 0.75` 变速，不额外占空间

### 体积与分包（2MB 主包红线）

| 位置 | 内容 | 体积 |
| --- | --- | --- |
| 主包 | 代码 + 英语朗读 140 条（112 句 + 28 行台词） | 约 **1321KB / 2048KB** |
| 分包 `packageJa` | 日语朗读 333 条（100 句 + 33 行台词 + 100 词 + 100 条例句） | 约 **1777KB / 2048KB** |

日语音频 1.8MB 塞不进 2MB 主包，所以放在分包 `packageJa` 里（分包必须至少有一个页面，
于是顺手做了「离线发音包」页，可从「统计 → 使用设置 → 离线发音包」进入，能试听、能看到加载状态）。
`app.js` 启动时就用 `wx.loadSubpackage({ name: 'jaAudio' })` 预载；分包没加载好之前
`localAudio.pathFor()` 返回空串，播放会退回在线链，不会给出一个必然失败的路径。

英语朗读放在主包里而不是分包：学英语是这个 App 的主场景，随包发布等于零下载延迟，
断网也不会突然没声音；剩下的 727KB 余量足够再放一门外语的句子。

素材改动后重新生成（需要 `pip install --break-system-packages edge-tts imageio-ffmpeg`）：

```bash
node tools/dump-items.js ja /tmp/ja_items.json
python3 tools/gen-audio.py --lang ja --items /tmp/ja_items.json --out packageJa/ja

node tools/dump-items.js en /tmp/en_items.json --no-words   # 英语不预生成单词，见下
python3 tools/gen-audio.py --lang en --items /tmp/en_items.json --out assets/audio/en

node tools/gen-local-audio.js    # 扫磁盘重新生成 utils/local-audio.js 清单
node tools/validate.js           # 主包/分包体积、页面四件套、JSON/JS 语法
```

合成脚本会跳过已存在的文件，只补新的；`--force` 可全部重生成。
英语**不预生成单词发音**：440 词 + 440 例句 = 880 个文件约 6MB，而单词的在线源（有道）一直稳定，
只有整句才会挂——把包体用在真正需要的地方。

`project.config.json` 的 `packOptions.ignore` 已把 `.md`、`tools/`、`tests/`、`deploy/` 排除出包。

## 学新词的顺序（为什么先学 keep 而不是 abandon）

词库数组是字母序，原实现直接 `filter(未学).slice(0, 5)`，等于**按字母表发词**：
新用户第一天的五个词是 `abandon`(COCA 2182) / `ability`(783) / `accept`(766) /
`access`(1113) / `accommodate`(3717)，第五个词在英语语料里排三千名开外。

现在改成**高频优先**：`utils/word-rank.js` 内置 439 个英语词的词频排名（数字越小越常用），
`storage.getNewWords()` 按排名升序取词。改完之后首日五个词是
`keep`(156) / `different`(237) / `book`(241) / `continue`(293) / `create`(332)。

- 数据来源：**ECDICT**（https://github.com/skywind3000/ECDICT）的 `frq`（COCA 词频排名）字段，
  `frq` 为 0 时退回 `bnc`（BNC 排名）；两者都为 0 的超低频词不收录，排序时排在最后。
- 日语词不进这张表（没有对应的日语语料库排名），保持词库原顺序。
- 分类筛选（四级/六级/日常…）仍然生效，两个条件叠加：先在分类内过滤，再按词频排序。

## 日语逐词高亮（TinySegmenter + 真实时长对齐）

逐词高亮原来按空格切词，而日语不写空格——整句只会被当成 1 个 token，
高亮对 62 个日语句子等于失效。两处改动：

- **切词**：`utils/tiny-segmenter.js`（TinySegmenter 0.1，作者 Taku Kudo，New BSD，
  18KB 纯 JS、无依赖）把日语句子切成 `私 / は / 中国 / から / 来 / まし / た` 这种粒度；
  英语仍按空格切，行为不变。
- **对齐**：高亮时间表原本按字数加权估算。现在音频 `canplay` 后读 `InnerAudioContext.duration`
  真实时长，`highlighter.retime()` 现场重排时间表（慢速播放会按 `playbackRate` 换算成实际耗时），
  高亮不会越走越偏。
- 日语的 token 之间不补空格（`toView()` 按语种决定），英语 token 自带一个尾随空格。

第三方代码只有这一个：`utils/tiny-segmenter.js`，文件头保留了原作者与许可信息，可随时替换回上游版本；
本地只改了两处（`regexp.compile` 换成标准 `new RegExp`、末尾补 `module.exports`）。

## 性能与流畅度

针对小程序"同步 Storage 慢、setData 大列表卡"两个主要卡顿源做了优化，纯内部改动，**用法完全不变**：

- **发音缓存**：每次听句子都要联网下载 mp3，而练一句通常是「标准音 → 慢速 → AB 复读」3~4 次，弱网下每次要等 200~400ms。现在第一次下载后复制进 `USER_DATA_PATH/tts`，之后同句直接放本地文件（0 请求），按「最久未使用」淘汰，上限 3MB（给录音让路）；缓存的本地文件坏了会自动删掉并退回在线重试。
- **数据读取缓存**：档案信息、进度/统计/设置、口语记录、在线词库缓存都加了进程内缓存，同步读次数从上百次降到个位数（实测首页一轮刷新从约 20+ 次同步读降到 2 次）；写入即时刷新、导入/切档案自动失效，不会读到脏数据。
- **查词页增量渲染**：内置 440 词不再一次性全渲染，首屏只显示 30 条，下拉"加载更多"；搜索历史改为按"搜索键"记录，不再每敲一个字都写 Storage。
- **统计页去重读取**：设置、每日数据、掌握数等只读取一次后复用。
- **学习页不传队列**：待复习/新词的队列只在页面内部流转，setData 只传「当前这一张卡 + 共几条」，400 词的队列（约 60KB）不再每次切页都跨线程搬一遍。
- **大列表增量渲染**：今日待练（最多约 990 项）、错词本（最多 440 项）首屏只渲染 30 条，下滑「加载更多」追加，不再一次性铺满页面；口语页队列超过 20 条时，进度指示从「每个条目一个圆点」改为「进度条 + 3 / 440」，节点数从上百个降到 2 个。
- **写入合并（延迟落盘）**：评一张卡原来要同步重写 progress/stats/daily 三个 key，学满 440 词时 progress 单张表就有 48KB，等于每点一下都往 Storage 塞几十 KB。现在热路径改成「内存立即生效、磁盘攒一批再落」，读永远读内存所以看不到延迟；1.5s 空闲、攒够 12 次、页面 `onHide`/`onUnload`、App 进后台、导入导出前都会强制落盘。实测连评 20 张卡从 60 次写 / 1.8MB 降到 15 次写 / 240KB。
- **进度不再清零**：口语、测验、学习三页切走再回来接着上次的位置练，不会重新随机题目、不会把「做到第 87 张」打回第 1 张（队列指纹没变就沿用，变了才重建）。
- **逐词高亮只在词边界唤醒**：原来每 60ms 轮询一次，3 秒音频要醒 50 次；现在按时间表算下一个词边界，唤醒次数≈词数（实测一段 4 词音频从 50 次降到 5 次）。换词时也只 setData 一个下标（16B），不再重发整个 token 数组（长句 447B）。
- **首页 `onShow` 不再空转**：`storage.init()` 改为按档案幂等 + 老数据迁移打一次性标记，重复调用 0 次同步读（原来每次回首页 16 次）。
- 缓存正确性有单元测试覆盖（读次数下降、写后即时可见、失效后能发现外部改动、延迟落盘的 flush 时机与攒批阈值、`init` 幂等、读出的对象是拷贝改不脏缓存）。
- **录音按体积+条数双淘汰**：微信给每个小程序 10MB 本地文件额度，录音保存时先按 30 条、再按总量 8MB（留余量）从最旧的删；万一还是写不进去，会自动删最旧一条重试一次。
- **异常兜底**：`app.js` 挂了 `onError` / `onUnhandledRejection` / `onPageNotFound`，页面出错不再静默白屏，页面路径失效会自动回首页；本地写入失败（空间满等）会明确提示用户先备份，不会让你以为进度已保存。

## 给家人朋友用（多人场景）

一台设备、一家人共用时，进首页点顶部「切换家人档案」：

- **每人一份独立进度**：档案间学习/口语/统计/录音完全隔离，不会串号。升级前的老数据自动归到名为「我」的默认档案。
- **儿童 / 长辈模式**：给每个档案单独设，字号自动放大（长辈超大字），界面更友好；也能在统计页手动微调字号/深色/震动。
- **家庭排行榜**：首页「家庭排行榜」看今天谁练得最多，可切换按连续天数、累计学词排。
- **全家录音墙 + 点评**：听家人录音，点「点评」写一句鼓励，互相打气。
- **邀请朋友**：首页「邀请朋友」转发卡片或复制文案；加体验成员扫码即用、免费免审核（详见 [上线合规清单.md](上线合规清单.md)）。
- **学习提醒**：本机能存提醒偏好；真定时推送需后台+模板 ID，页面内给了手机闹钟等免费替代。
- **全家包备份**：统计页「导出全家包」把一家人所有档案+录音一次性复制成文本，换设备「导入全家包」可选合并或覆盖，全家搬家不丢数据。

数据始终只在这台设备的微信里，不联网、不上传。想给另一台设备用，用「统计 → 导出/导入进度」或「导出/导入全家包」迁移。哪些功能受"零后端"限制做不到，见 [能力与边界说明.md](能力与边界说明.md)。

## 关于发音客观评分（进阶可选，现阶段可忽略）

默认使用**自评**（再练练/基本流利/很流利），导入即可用、无需任何后台配置。

**客观发音分**现在接的是**智聆口语评测**插件（`ihearing-eval`，provider `wx63d6102e26f0a3f8`）：它自己做声学评测，直接返回发音准确度/流畅度/完整度，以及每个词是「读错/漏读/多读/生词」，比原来「同声传译转文字再算相似度」准得多——后者测的其实是识别器猜没猜对，不是发音好不好。

⚠️ **插件需要先在小程序后台申请添加**（设置 → 第三方设置 → 插件管理 → 搜索「智聆口语评测」），否则 `app.json` 里的声明会让项目编译报错。如果暂时不想加，删掉 `app.json` 里的 `plugins` 块即可，代码自动降级为纯自评，功能不受影响。详见 **[智聆评测接入说明.md](智聆评测接入说明.md)**。

## 换设备迁移进度

在「统计」页点**导出进度**，备份数据（含学习/口语/打卡）复制到剪贴板，粘贴到备忘录/微信收藏保存；换设备后点**导入进度**粘贴即可恢复。全程不联网、不需要账号。导入时会自动迁移旧版本数据。

## 扩展素材 / 多语言

- **加单词**：编辑 `utils/words.js` 的 `WORDS.en` 数组，按现有字段填写即可。
- **加句子/对话**：编辑 `utils/sentences.js` 的 `SENTENCES` / `DIALOGUES`，`level` 填 A1/A2/B1/B2 即可自动出现在难度筛选。
- **不写代码加素材**：口语页 →「📥 导入素材」，每行一句 `英文|中文`，保存后切到「✏️ 自建」跟读。
- **加语种**：在 `WORDS`、`SENTENCES`、`DIALOGUES` 下各加语种键，并在 `getLangMeta()` 补语种名和 TTS 代码；首页 `pages/index/index.js` 的 `langs` 数组同步加上。示例日语词库已内置。

## 运行单元测试

纯函数（FSRS/高亮/徽章/相似度/素材数据）有 Node 单元测试：

```bash
node tests/run-tests.js
```

## 在线词库更新（可选，需你自己的备案域名）

默认完全离线、用内置词库。若你有**已备案的 https 域名**，可把词库放上去，以后加词改句**不用重新提交小程序版本**：

1. 按 **[在线词库部署-OSS.md](在线词库部署-OSS.md)** 把 `deploy/data.json` 传到阿里云 OSS 并绑定备案域名。
2. 把得到的 https 地址填进 `utils/online-data.js` 的 `DATA_URL`（留空即不启用）。
3. 小程序后台把该域名加进 **request 合法域名**（测试号可先跳过）。

拉不到 / 没配置时自动用内置词库，**完全无感**。以后更新：改素材 → 跑 `node deploy/export-data.js` → 覆盖上传 `data.json` 即可。

## 已知说明

- 发音依赖第三方公开接口，弱网/离线时会自动切换备用源并给出提示；如需完全离线，可配置「微信同声传译」插件替代。
- 录音回放用微信原生 `RecorderManager` + `InnerAudioContext`；录音文件保存到本地（最近 30 条），超量自动删除最旧的，避免占满空间。
- 发音客观评分依赖**智聆口语评测**插件（可选）；未添加插件、日语（插件不支持）或评测失败一律静默降级为纯自评，绝不阻断练习。
- 统计图表用原生 Canvas 2D 绘制，未引入任何第三方图表库。

## 进阶（可选）：启用发音客观评分

`app.json` 里已经声明了智聆插件，**但插件本体要先在后台申请添加，否则编译会报「找不到插件」**：

1. 登录微信公众平台 → 设置 → 第三方设置 → 插件管理 → 添加插件
2. 搜索「智聆口语评测」，或直接搜 AppID `wx63d6102e26f0a3f8`，申请并等待通过
3. 通过后回开发者工具重新编译，`utils/speech-score.js` 会自动检测到插件并启用评测，**无需改其他代码**
4. 不想加插件：删掉 `app.json` 的 `plugins` 块即可，所有功能照常，只是没有客观分数

配额默认 2000 次/小时/小程序；评测只支持中英文，日语自动走自评。完整说明见 **[智聆评测接入说明.md](智聆评测接入说明.md)**。
