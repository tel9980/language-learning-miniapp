# 语伴 · 外语学习小程序

一个纯前端、零后端、开箱即用的微信小程序，**以口语练习为核心**：录音跟读 + 回放对比 + 重点复练，辅以单词卡片、间隔重复复习、小测验、查词、错词本和进度统计。英语为主（内置 220 词），结构上预留多语言扩展。

## 导入与运行

1. 打开 **微信开发者工具** → 导入项目
2. 目录选择本文件夹（`语言学习小程序`）
3. AppID 可选择「测试号」（`project.config.json` 里已填 `touristappid`，直接用游客模式也能跑）
4. 点击「编译」即可在模拟器里使用；口语录音建议在真机预览上体验

发音功能使用有道公开 TTS 接口，**需联网**；录音用微信原生录音能力，需授权麦克风。

## 功能说明

| 页面 | 功能 |
|---|---|
| 首页 | 今日口语次数/打卡/掌握概览、口语练习主入口、今日复习目标、点击右上角切换语种 |
| **口语** | 核心页：听标准音/慢速/例句 → **录音跟读** → **听自己的回放对比** → 三档自评（再练练/基本流利/很流利）；「再练练」自动进重点复练清单 |
| 学习 | 卡片翻转看释义；三档记忆评分；艾宾浩斯间隔（1/2/4/7/15/30 天）自动排期复习 |
| 测验 | 随机 10 题（选择题 + 拼写题），即时判定、显示例句，结束给出正确率 |
| 统计 | 口语数据（练过/流利/重点待练）、近 7 天复习柱状图、词汇掌握分布、每日目标、进度导出/导入 |
| 查词 | 按单词/释义/例句实时搜索，按分类筛选，点击展开例句、听发音 |
| 错词本 | 自动收集答错过的词，按错误次数排序，集中重练 |

口语练习流程（tabBar 第 2 项「口语」）：

```
听标准发音 / 慢速 → 看例句跟着说 → 点麦克风录音 → 听我的回放对比
      → 自评：🔁再练练（进重点清单） / 👍基本流利 / 🌟很流利（移出清单）
      → 首页/口语页顶部「🎯 重点复练」一键集中攻克说得不好的词
```

所有学习进度和口语记录都存在微信本地 `Storage`，无需登录、不上传任何数据。

## 换设备迁移进度

在「统计」页点**导出进度**，备份数据会复制到剪贴板，粘贴到备忘录/微信收藏保存；换设备后点**导入进度**粘贴即可恢复。全程不联网、不需要账号。

## 扩展词库 / 多语言

- **加单词**：编辑 `utils/words.js` 的 `WORDS.en` 数组，按现有字段填写即可。
- **加语种**：在 `WORDS` 下新增一个语种键（如 `ja`），并在 `getLangMeta()` 里补语种名和 TTS 代码；首页语种切换数组（`pages/index/index.js` 的 `langs`）同步加上即可。示例日语词库已内置。

## 已知说明

- 发音依赖第三方公开接口，弱网/离线时会有提示；如需完全离线，可在小程序后台配置「微信同声传译」插件替代。
- 录音回放用微信原生 `RecorderManager` + `InnerAudioContext`，仅保存在本次会话内（不永久存储音频，避免占用空间）；练习记录和自评结果会持久保存。
- 统计图表用原生 Canvas 2D 绘制，未引入任何第三方图表库。
